Genera un sistema web completo con backend en Django + Django REST Framework y frontend en React, siguiendo arquitectura modular y escalable. Incluye:

### 1. Inicialización de Ambientes
- Backend: Django + Django REST Framework + PostgreSQL (fallback SQLite).
- Frontend: React con componentes modulares y consumo de API REST.
- Dockerización: contenedores separados para backend, frontend y base de datos.
- Scripts de inicialización para levantar ambos ambientes con `docker-compose up`.

### 2. Autenticación y Seguridad
- Login con correo y contraseña.
- Configuración de tiempo de sesión (administrador define minutos).
- Cambio de contraseña por usuario con confirmación vía correo.
- Restablecimiento de contraseña por administrador con envío de contraseña temporal.
- Roles: Administrador (gestiona todo) y Técnico (solo instalaciones, reparaciones, salidas asignadas).
- Notificación por correo al registrar técnicos.
- Seguridad: hashing de contraseñas, CSRF, XSS prevention.

### 3. Inventario
- Entrada de productos (múltiples en lote).
- Salida de productos (individual, con serial obligatorio o autogenerado).
- Tipos de salida: Permanente o Préstamo.
- En préstamos: fecha fin obligatoria y alerta automática si vence.
- Adjuntar documentos/fotos en entradas y salidas.
- Generar comprobantes PDF imprimibles con espacio para firmas (entrega/recepción).

### 4. Reparaciones
- Registro de reparaciones por producto.
- Detalle de qué se reparó (ej. cambio de batería, soldadura).
- Tracking histórico: cuántas veces se reparó cada producto.
- Reportes de mantenimiento por producto.

### 5. Instalaciones
- Salida de producto → técnico asignado → registro de instalación en ubicación.
- Estado del producto cambia a “instalado”.

### 6. Solicitantes
- En salida: si solicitante no existe, registrarlo inline (nombre, apellido, cédula, ubicación, nota).
- Pantalla independiente para administrar solicitantes (agregar, modificar, deshabilitar, nunca borrar).

### 7. Catálogos de Configuración
- Pantallas CRUD (agregar, modificar, deshabilitar):
  - Ubicaciones (almacén, taller, cliente).
  - Marcas.
  - Modelos (asociados a marcas).
  - Categorías de productos.
  - Estados de productos (almacenado, instalado, en reparación, prestado, descargado).

### 8. Préstamos
- Pantalla para buscar artículos prestados (filtros: producto, solicitante, técnico, ubicación, estado).
- Reporte PDF imprimible con listado de préstamos vigentes, vencidos y devueltos.
- Espacio para firmas en el reporte.

### 9. Frontend React
- Formularios dinámicos para entradas, salidas, instalaciones, reparaciones.
- Tablas con filtros y estados visuales (ej. préstamos vencidos en rojo).
- Botones para subir documentos/fotos y generar comprobantes PDF.
- Panel de administración para catálogos y usuarios.
- Dashboard con alertas de préstamos vencidos y cambios de estado.

### 10. Auditoría
- Registro histórico de todas las acciones (entradas, salidas, instalaciones, reparaciones, cambios de contraseña).
- No se borra nada de la base de datos, solo se deshabilita para mantener histórico.

### 11. Entregables
- Código fuente completo (backend Django + frontend React).
- Migraciones de base de datos (PostgreSQL/SQLite).
- Scripts de inicialización y docker-compose.
- Documentación técnica (Swagger/OpenAPI).
- Manual de usuario básico.

Genera todo el código en Visual Studio Code, con estructura modular y buenas prácticas.

    marca = models.ForeignKey(Marca, on_delete=models.CASCADE)
