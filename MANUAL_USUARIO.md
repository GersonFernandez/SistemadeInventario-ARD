# Manual de Usuario Basico

## 1. Acceso al sistema

1. Abra el navegador y entre a la URL del frontend.
2. Inicie sesion con correo y contrasena.
3. Si olvido su contrasena, contacte al administrador para restablecimiento temporal.

## 2. Roles

- Administrador: gestiona usuarios, configuracion de sesion, auditoria y catalogos.
- Encargado de Inventario: gestiona inventario, despachos, prestamos y solicitantes.
- Tecnico: consulta y opera en flujos asignados (despachos/prestamos segun permisos).

## 3. Inventario

1. Vaya a Inventario.
2. Cree articulos con categoria, ubicacion y stock inicial.
3. Adjunte imagen/documento cuando aplique.
4. Para herramientas serializadas, agregue unidades fisicas con serial.

## 4. Despachos (salidas)

1. Vaya a Despachos -> Nuevo despacho.
2. Seleccione solicitante (puede crearlo en linea).
3. Agregue articulos o unidades por serial.
4. Confirme el despacho.
5. Desde el detalle, descargue el comprobante PDF con espacio de firmas.

## 5. Prestamos

1. Vaya a Asignaciones para gestionar prestamos activos.
2. Puede extender fecha de devolucion.
3. Registre devoluciones al recibir herramientas.
4. Genere reporte PDF de prestamos vigentes/vencidos/devueltos.

## 6. Solicitantes

1. Vaya a Solicitantes.
2. Agregue o edite nombre, rango, cedula, ubicacion y nota.
3. Para conservar historial, los solicitantes se deshabilitan en lugar de borrarse.

## 7. Seguridad y contrasenas

- Seguridad -> Cambiar contrasena: el sistema enviara confirmacion por correo.
- Usuarios (admin): puede enviar contrasena temporal a cualquier usuario.
- Usuarios (admin): puede configurar minutos de sesion por inactividad.

## 8. Auditoria

Todas las operaciones sensibles quedan registradas en el modulo de Auditoria.
No se recomienda eliminar registros historicos.
